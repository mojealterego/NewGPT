# Third-party components

## llama.cpp

NewGPT uses the upstream llama.cpp project for local GGUF inference.

- Repository: https://github.com/ggml-org/llama.cpp
- Pinned version: v0.4.1
- Integration: CMake FetchContent + JNI
- Target Android ABI: arm64-v8a and x86_64

See the upstream project for its current license, notices and release information.
